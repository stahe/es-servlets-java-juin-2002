# Servlets de Java – Junio de 2002

🔗 Curso en línea: https://stahe.github.io/es-servlets-java-juin-2002/

## Introducción

Este documento es un **folleto del curso** dedicado a la programación web en Java (Servlets, entorno J2EE).

No se trata de un curso completo. Algunos temas requieren la orientación de un instructor, y hay varios temas importantes que no se tratan.

El objetivo principal es proporcionar a los alumnos las herramientas necesarias para trabajar de forma autónoma en los fundamentos del desarrollo web en Java.

## Referencias bibliográficas

Las principales obras de referencia son:

1. *J2EE Programming* – Wrox (distribuido por Eyrolles)
2. *Java Server Pages* (Fields, Kolb) – Eyrolles
3. *Java Servlet Programming* (Hunter) – O'Reilly

Gran parte del contenido se basa en el primer libro, que es mucho más completo que este recurso.

## Temas adicionales no tratados

Este documento podría mejorarse añadiendo los siguientes temas:

- Programación XML
- Etiquetas JSP
- EJB (Enterprise Java Beans)

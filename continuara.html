    En este documento hemos proporcionado información suficiente para iniciarse en la programación web con Java. Algunos temas solo se han tratado de forma superficial y merecen un análisis más detallado:

    • XML (eXtended Markup Language), CSS (Cascading Style Sheets) y XSL (eXtended Stylesheet Language)

    Hemos abordado estos temas, pero aún queda mucho por hacer. En conjunto, merecen un folleto aparte.

    • JavaScript

    Hemos utilizado algunos scripts de JavaScript aquí y allá que se ejecutan en el navegador, sin entrar nunca en detalles sobre ellos. Por ejemplo, nunca hemos profundizado en el lenguaje JavaScript. Debido a la falta de espacio y tiempo. Este lenguaje por sí solo también podría requerir un libro propio. Hemos incluido tres ejemplos significativos de JavaScript en el apéndice, de nuevo sin explicarlos. No obstante, se entienden simplemente leyendo sus comentarios y pueden servir como ejemplos.

    • JavaBeans, etiquetas JSP

    Hemos mostrado cómo podemos separar el código Java y el código HTML en una aplicación web. El código Java se agrupa en uno o más servlets, y el código HTML en una o más páginas JSP. Sin embargo, en nuestros ejemplos, a menudo quedaban unas pocas líneas de código Java en las páginas JSP. Podemos mejorar esto utilizando componentes llamados JavaBeans y etiquetas JSP predefinidas —o etiquetas que crees tú mismo— en las páginas JSP. Este aspecto de las páginas JSP no es esencial (nos las arreglamos perfectamente sin él en nuestros ejemplos realistas), pero no obstante es útil conocerlo.

    • Enterprise Java Beans (EJB)

    Los EJB son componentes proporcionados por los contenedores en los que se ejecutan los servlets y las páginas JSP. Proporcionan servicios «del sistema» que ahorran al desarrollador un trabajo de desarrollo largo y difícil. Los servicios proporcionados por los EJB pueden abarcar las siguientes áreas: transacciones, seguridad, agrupación de conexiones a bases de datos, ...

    Todos estos temas, que no se tratan aquí, se abordan de forma excelente en el libro «J2EE Programming», publicado por WROX y distribuido por Eyrolles.
